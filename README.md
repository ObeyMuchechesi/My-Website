Marketing site for Digitek Solutions (founded by Obey Muchechesi) — websites, web apps and custom software.

**Live:** https://obeymuchechesi.github.io/My-Website/

## Run locally

Open `index.html` in any browser — single file, no build step, no dependencies.

## Notes

- Social share image: `og-image.png` (referenced by the Open Graph meta tags).
